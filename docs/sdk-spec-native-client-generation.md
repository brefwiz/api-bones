# Native client generation contract

This document describes the native surface. The repository-wide SDKSpec is
recorded separately as review evidence against an immutable commit, including
every normalized surface and target; it is not self-versioned in this file.

## Normalized surface

- Surface: `native-client-generation`
- Contract: `tests/features/native_client_generation.feature`
- Targets: Rust, TypeScript
- Rust delivery: published `api-bones-sdk-gen` package
- TypeScript delivery: conformance output generated and compiled by the Rust
  generator; no TypeScript package is published by this repository
- Canonical RPC endpoints: none
- Canonical source: protobuf descriptor set, including
  `bones.v1.native_services` file option
- Generator entrypoints: `api-bones-sdk-gen native` and
  `protoc-gen-bones-native` through normal buf/protoc plugin protocol

## Contract

- Descriptor metadata is a repeated protobuf `FileOptions` extension. Native
  declarations do not create protobuf services or RPC methods.
- Plugin honors `CodeGeneratorRequest.file_to_generate`; imported files resolve
  descriptors but do not cause output for unrequested native declarations.
- Plugin returns an empty successful response for selected files without native
  declarations, including descriptor sets that do not import native annotations.
  Malformed native declarations still fail generation.
- Buf configuration uses `strategy: all`; one deterministic output per target
  combines selected native declarations across source directories.
- Rust emits package-qualified client names, `Vec<u8>` payloads and ack handles,
  async publish/deliver/ack/nak methods, `NativeTransport`, `CallOptions`, and
  typed `NativeError` results.
- TypeScript conformance output contains equivalent package-qualified clients,
  `Uint8Array` payloads
  and ack handles, Promise/AsyncIterable methods, `NativeTransport`,
  `CallOptions`, and typed `NativeError` results.
- Message and entity identity pass unchanged. Payload bytes are never converted
  through JSON, text, or Base64.
- Permission denial, cancellation, deadline expiry, transport failure, and used
  ack handle remain distinguishable typed outcomes.
- Generated clients refuse calls already cancelled or expired before dispatch.
  Transport implementations must observe cancellation and deadline during an
  in-flight operation; generator does not claim to schedule a timer itself.
- Ack handles are one-shot after success. Failed, cancelled, or dropped
  attempts release pending state so same delivery can be retried. Success alone
  consumes handle, preserving at-least-once/redelivery semantics.
- TypeScript ack transitions are module-private. Public handle exposes only
  opaque bytes. Rust uses drop guard to release pending state.
- Output is deterministic. Check mode compares expected bytes to existing
  artifacts and fails with target path without overwriting stale output.
- Invalid identifiers, target-language reserved API names, post-conversion name
  collisions, duplicate operations, and duplicate package/service declarations
  fail generation. Package-qualified names disambiguate equal short names.
- Existing OpenAPI generation and Connect packages remain unchanged.

## Parity matrix

| Scenario | Rust | TypeScript |
|---|---|---|
| Opaque publish and stable identity | generated `publish`; exact request/result asserted | generated `publish`; exact request/result asserted |
| Durable delivery and ack | generated stream and `acknowledge`; exact delivery/handle/op/options | generated iterable and `acknowledge`; exact delivery/handle/op/options |
| Durable delivery and nak | generated stream and `negative_acknowledge`; exact delivery/handle/op/options | generated iterable and `negativeAcknowledge`; exact delivery/handle/op/options |
| Ack one-shot | typed `ack_handle_used` transport error | typed `NativeError` used-handle failure |
| Nak one-shot | later ack/nak rejected with zero dispatch | later ack/nak rejected with zero dispatch |
| Failed ack retry | failed future resets guard; same handle succeeds | rejected Promise resets private state; same handle succeeds |
| Interrupted ack retry | dropped pending future resets guard; same handle succeeds | cancelled/rejected attempt resets private state; same handle succeeds |
| Failed nak retry | failed future resets guard; same handle succeeds | rejected Promise resets private state; same handle succeeds |
| Typed provider denial | `PermissionDenied` | `permission_denied` `NativeError` |
| Option propagation | exact `Arc` cancellation identity and `Instant` | exact `AbortSignal` and `Date` object identity |
| Already-cancelled preflight | typed error, zero dispatch | rejected Promise, zero dispatch |
| Expired-deadline preflight | typed error, zero dispatch | rejected Promise, zero dispatch |
| Determinism and zero RPC inventory | generated bytes compared; descriptor method count zero | generated hashes compared; proof RPC count zero |
| Malformed descriptor | exact duplicate-operation diagnostic | exact CLI proof diagnostic |
| Stale checked output | check mode rejects Rust and TypeScript stale paths | generated proof records both exact stale diagnostics |
| Async cancellation shape | async result resolves to typed error | method returns Promise before rejection is observed |
| Identifier safety | invalid/collision fixtures and package disambiguation | same fixtures/proof and package-disambiguated classes |
| Plugin protocol and selection | actual buf plugin emits and compiles selected Rust client; requested file only | actual buf plugin emits, compiles, and executes selected TypeScript client; requested file only |
| Ordinary RPC-only plugin input | successful response emits zero Rust files | successful response emits zero TypeScript files |
| Multi-directory plugin input | `strategy: all` emits one Rust file containing every selected client | `strategy: all` emits one TypeScript file containing every selected client |
